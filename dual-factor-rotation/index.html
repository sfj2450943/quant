🧮 双因子定义与打分

权重/阈值可在源码中调整

因子一 · 动量（20日BIAS，果仁口径）

BIAS20 = 后复权收盘价 / 20日复权均价 − 1

20日复权均价 = 近20日后复权收盘价的算术平均（复权版MA20）。衡量价格相对20日均线的偏离，反映短期趋势强度。BIAS 越高，动量越强、趋势越向上。与 (现价−MA20)/MA20 数学等价，但须用后复权价以避免分红除息跳变。

因子二 · 风险（60日波动率，果仁口径）

Vol60 = stdev(当日涨幅, 60) × √60

当日涨幅 = 后复权收盘价 / 前收盘价 − 1；取近60个日收益的样本标准差（果仁 stdev 为样本标准差，除以 N−1，而非总体标准差 ÷N），再乘 √60 为果仁自定义年化尺度（非标准 √252，数值约为标准年化的 0.49 倍）。越低代表走势越稳健，轮动中优先选低波动标的以控制回撤。

综合得分 · 排名打分法（各 1~12 分相加）

综合得分 = BIAS排名得分 + 波动率排名得分（满分 24）

两因子各自在全池内独立排名：BIAS20 越大 → 排名越靠前 → 得分越高（第1名12分 … 第12名1分）；Vol60 越小 → 排名越靠前 → 得分越高（第1名12分 … 第12名1分）。将两项排名得分相加得综合得分，按综合得分降序排列，优先持有综合得分最高者。

资格门槛：仅 250日累计涨跌幅 > 0 的 ETF 进入候选，参与上述排名打分与前5买入；≤0 者整行置灰标「不达标」，不参与轮动。

开平规则（示例）：目标持仓为综合得分前5名（同时持有）。当前持仓中跌出前5的→卖出；前5中尚未持有的→买入；仍在前5的→继续持有。阈值与规则细节可在源码 calcDecision() 调整。
